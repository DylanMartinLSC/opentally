# Example images

`blocks.jpg`, `apples.jpg` and `boards.jpg` are rendered scenes from the
**MixCount** dataset (test split: `test/p2/...`, see `examples.json` for each
source path), by Corentin Dumery et al., arXiv:2605.18063.

- Source: https://huggingface.co/datasets/CorentinDumery/MixCount
- License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- Changes: re-encoded as JPEG (quality 85). Not otherwise modified.

`examples.json` lists the dataset's ground-truth count for every kind of object
in each scene, so you can check OpenTally's answers.
